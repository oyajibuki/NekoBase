# NekoBase — ゲスト用ページ

多頭飼いのお世話アプリ「ネコベース」の、親戚・お手伝いの方に渡すリンクの表示ページです。

- 表示しているのは `docs/index.html` 1枚だけ（GitHub Pages）
- データの読み書きと権限の判定は Supabase Edge Function 側にあります
- 招待トークンは URL の `#` 以降に置いているので、サーバーのログや Referer には残りません
- 鍵やパスワードの類はこのリポジトリに含まれていません

ページ単体を開いても何も表示されません。飼い主が発行した招待リンク（`.../NekoBase/#<token>`）から開いてください。
