ネコベース サポート

猫のお世話を、家族や親戚と分け合うためのアプリです。

うまくいかないこと、ご要望、不具合の報告はこちらへ。
できるだけ早くお返事します。

お問い合わせフォーム メールで問い合わせる

はじめかた

  1. 設定 →「あなたの名前」を入れます。お世話の記録に「誰がやったか」が残ります。
  2. 設定 → 猫で、猫の名前と写真を登録します。
  3. 設定 →「おすすめのお世話を入れる」で、朝晩のごはん・水かえ・遊ぶ・トイレチェック（猫の数＋1個）・うんち拾い（猫ごと）が入ります。要らないものはスワイプで消せます。
  4. 在庫 →「よく使うものを追加」で、カリカリ・チュール・おやつ・トイレシート・猫砂・うんち袋が入ります。保管場所の写真とピンを登録しておくと、留守番をお願いする人が迷いません。

よくある質問

親戚に留守番をお願いしたい。アプリを入れてもらう必要はありますか？

いりません。設定 →「招待リンクを作る」で発行したリンクを渡してください。ブラウザで開くだけで、その日のお願いリスト・保管場所の写真・写真つきの完了報告ができます。アカウント登録も不要です。

家族とも共有したい

家族が自分の iPhone でアプリを使う場合は、設定 →「家族と共有する」→「招待コードを作る」。相手の端末でそのコードを入れると、同じ猫と記録が見られるようになります。

アプリを入れられない家族には、同じ画面の「Webリンクを作る」。ブラウザだけで、今日のお世話のチェック、猫ごとのうんちの確認状況、在庫の残量まで見られます。

うんちを片付けたのに「まだ確認できていない子」に出ます

その猫の「うんち拾い」を完了にすると消えます。「出ていない」を選んだときだけ、確認できていない扱いのまま残ります。

うんち拾いのタスクが無い猫は、判断のしようがないため表示されません。設定 → お世話タスクで、対象の猫を選んだ「うんち拾い」を追加してください。

お知らせ（通知）が来ません

  • iPhone の「設定」→「通知」→「ネコベース」で通知が許可されているか確認してください。
  • お知らせはお世話ごとに設定します。設定 → お世話タスク →（タスクを選ぶ）→「時間になったら知らせる」。
  • その日のぶんを済ませたタスクは鳴りません。

写真はどこに保存されますか？

お世話の報告写真は端末の中だけに保存されます。保管場所のガイド写真と猫のプロフィール写真は、家族や親戚に見せるためにクラウド（Supabase・日本国内）へ保存されます。詳しくはプライバシーポリシーをご覧ください。

機種変更したい

設定 →「Apple で続ける」で Apple ID を紐づけておいてください。新しい端末で同じ Apple ID でサインインすると、同じ記録に戻れます。紐づけをしないまま端末を失うと、復旧する手段はありません。

ネコベース プラスの解約方法

iPhone の「設定」→ 一番上のご自分の名前 →「サブスクリプション」→「ネコベース」→「サブスクリプションをキャンセル」。アプリ側では解約できません。

購読は自動更新され、期間終了の24時間前までに解約しない限り同額で更新されます。

機種を変えたら課金が消えました

課金画面の「購入内容を復元する」を押してください。購入時と同じ Apple ID でサインインしている必要があります。

データを全部消したい

アプリ内で記録を削除すると、クラウド上のデータも削除されます。アカウントごとすべて削除したい場合は、下記メールアドレスへご連絡ください。

招待リンクを止めたい

設定 →「招待リンクを作る」の一覧で、該当のリンクを左にスワイプして「停止」または「削除」。停止したリンクを開いても、中身は表示されません。

対応環境

  • iOS 18.0 以降の iPhone / iPad
  • 招待リンクは、スマートフォンやパソコンのブラウザで開けます（アプリ不要）
