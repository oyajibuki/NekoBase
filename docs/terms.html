ネコベース 利用規約

最終更新日: 2026年9月15日

この規約は、猫のお世話を家族や親戚と分担するアプリ「ネコベース」（以下「本アプリ」）の利用条件を定めるものです。本アプリを利用された時点で、この規約に同意いただいたものとします。

1. できること

本アプリは、猫のお世話の記録・在庫の管理・かかった費用の記録を行い、家族や親戚と分担するためのものです。獣医療の代わりになるものではありません。健康上の判断は必ず獣医師にご相談ください。

2. アカウント

本アプリは端末ごとの仮アカウントで動きます。Apple ID を紐づけると、機種変更や端末の紛失があっても同じ記録に戻れます。紐づけをしないまま端末を失った場合、記録を復旧する手段はありません。

3. 招待リンクについて

親戚や家族に渡すリンクは、リンクを知っている人なら誰でも開けます。その日のお世話の内容と、保管場所の写真が表示され、完了報告ができます。不要になったリンクはアプリから停止・削除してください。

4. ネコベース プラス（有料購読）

  • 毎日のお世話・在庫・おかねの記録・通知は、無料のままで利用できます。
  • プラスでは、家族との共有、招待リンクの人数制限の解除、写真のクラウド保存、全期間の費用グラフが利用できます。
  • 料金は購入時に App Store に表示される金額です。購読は自動更新され、期間終了の24時間前までに解約しない限り同額で更新されます。
  • 解約は iPhone の「設定」→ Apple ID →「サブスクリプション」から行えます。アプリ側では解約できません。
  • 支払いは Apple のアカウントに請求されます。返金についても Apple の規定に従います。

5. 禁止事項

法令に反する行為、本アプリの運営を妨げる行為、他の利用者の情報を不正に取得する行為はご遠慮ください。

6. 免責

本アプリは現状のまま提供されます。通信状況やサーバーの都合により、一時的に利用できないことや、記録が反映されないことがあります。本アプリの利用によって生じた損害について、作者は責任を負いかねます。

7. 規約の変更

必要に応じてこの規約を変更することがあります。重要な変更があるときは、アプリ内またはこのページでお知らせします。
